This module provides online bank statements from
`Moss <https://www.getmoss.com>`__.

It pulls the card transactions of your Moss organisation through the
`Moss public API <https://developers.getmoss.com/>`__
(``GET /v1/expenses``) and imports them as bank statement lines of a
credit card journal. Purchases are imported as negative amounts, refunds
and cashbacks as positive amounts. Only settled (accepted) card
transactions are imported, pending ones are picked up once they settle.

Each statement line carries the merchant as partner name, the amount in
the journal currency and, for purchases in another currency, the
original amount as foreign currency amount. Card, receipt, merchant and
FX fee details are kept in the notes of the line.

The module only reads from Moss. It never changes anything in Moss, in
particular it does not update the export status of expenses.

Configuration
=============

On the Moss website
-------------------

1. Log in to Moss as an admin.
2. Go to *Settings > Platform > API Keys* and create a new API key.
   Confirm the operation in the Moss mobile app.
3. Copy both the Key ID (``kid_...``) and the Secret Key (``sk_...``).
   The Secret Key is only shown once.

On Odoo
-------

To configure online bank statements provider:

1. Add your user to the "Full Accounting Settings" group.
2. Go to *Invoicing > Configuration > Accounting > Journals*.
3. Select the journal representing your Moss cards (or create it, type
   *Bank*). The journal currency, or the company currency if the journal
   has none, must be the home currency of your Moss organisation or the
   currency of your cards.
4. Set *Bank Feeds* to *Online (OCA)*.
5. Select *Moss* as online bank statements provider in *Online Bank
   Statements (OCA)* section.
6. Save the journal and click on the created provider.
7. Put the Key ID and Secret Key into the corresponding fields.
8. Optionally adjust the *Moss Date Margin*. Moss filters card
   transactions by expense date, which is the receipt date when a
   receipt is attached. The pulled period is extended by this margin on
   both sides so that such transactions are not missed; already imported
   transactions are never duplicated.
9. Configure the schedule and the statement creation mode and save.

In developer mode the *API Base URL* field allows to point the provider
to the Moss staging environment (``https://public-api.runmoss.run``).

Usage
=====

To pull historical bank statements:

1. Go to *Invoicing > Configuration > Online Bank Statement Providers*
2. Open the Moss provider
3. Click *Pull Online Bank Statement*
4. Configure date interval and click *Pull*

Statement lines are dated by the booking date of the card transaction in
Moss (falling back to the settlement date and the transaction time).

Currencies
----------

Moss provides every card transaction in the card currency and in the
home currency of the organisation. The journal currency (or the company
currency if the journal has none) must be one of them, usually the home
currency.

For transactions in another currency than the journal currency:

-  If the currency is available in Odoo, the original amount is kept as
   foreign currency amount on the statement line.
-  If the currency is not available in Odoo, the original amount and
   currency are added to the label and the notes of the line. Activate
   the currency in Odoo if you want future lines to carry it as foreign
   currency amount.

Known issues / Roadmap
======================

-  Verify against live data whether the card transaction amount reported
   by Moss already includes FX fees. FX fee lines are currently only
   listed in the notes of the statement line.
-  Attach the receipts of the matching Moss expense to the statement
   line (``POST /v1/files/search-query``,
   ``GET /v1/files/{fileId}/content``).
